# 打包支持：资源目录映射 + 打包后 data/ 解析

## 改动与原因

- `tauri.conf.json` 的 `bundle.resources` 由列表改为映射
  `{"../../../data/*.toml": "data/"}`：原先 `..` 路径在 bundle 里被转义成
  `Contents/Resources/_up_/_up_/_up_/data/`，打包后路径不可控；映射后稳定落到 `Contents/Resources/data/`。
- `AppState` 的数据目录解析顺序明确为：`JXCG_DATA_DIR`（显式指定，无效报错）→
  Tauri `resource_dir()/data`（打包后的 .app/安装包）→ `jxcg_core::store::resolve_data_dir()`
  （exe 同目录 data/，debug 下回退仓库 data/）。
- 计算/排行/转换/行情/数据命令统一带 `AppHandle`，从 `AppState::catalog(&app)` 取缓存目录。

## 关键决策

- 打包后不再依赖「exe 同目录 data」，统一走 Tauri 资源目录；开发期仍可用仓库 data/ 或 `JXCG_DATA_DIR`。
- 资源映射保留 glob，P4 数据更新时替换 data/ 重新构建即可（后续接数据通道再改成运行时下载）。

## 回归验证

- `cargo check -p jxcg_app` 通过；`bun run tauri build --bundles app` 出 `JXCG.app`，
  检查 `Contents/Resources/data/*.toml` 存在、启动冒烟通过（待本轮验证）。
