# 前端：中间产物摊入展示 + 排行排除开关（task-6）

## 改动与原因

- 接入「中间产物（产物∩材料）按自制成本摊入」的后端能力：
  - 设置页新增「中间产物按自制成本摊入」开关（默认开，随 Settings 持久化，旧存档缺字段自动补 true）；
  - 计算页：材料表中自实行来源徽标「自制」、单价=单位自制成本，行内可展开「明细」（产出配方/数量/单位成本/摊入小计/精力 + 一层采购原料）；
    结果卡新增「中间产物摊入」「中间产物精力（点）」，footer 区分 材料（含自制）/ 精力（最终）/ 中间产物精力 / 制作费 / 保管费；
    选中「只产中间产物」的配方时显示「中间产物 / 自用成本」徽标与「仅作成本参考、默认不进入成品排行」，不再用「可做/亏损」误导演示；
  - 排行页：默认排除只产中间产物的配方，新增「包含中间产物」勾选（RankPrefs v1→v2 迁移），行上打「中间产物」徽标；
  - 请求改为 `jiage` 全量行情 + `shoudong` 手填 id 集合（含计算页本地 overrides），保证递归深层材料能取到行情价、手填价阻止展开；
  - 浏览器 mock 同步派生中间产物集合与递归展开近似，补演示数据。
- `jingli_zhongjian` 是精力点数（u32），UI 按「点」展示；`mei_jingli` 由后端按总精力计算。
