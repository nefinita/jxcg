# P4：五行石精炼 UI（app-ui / task-4）

## 改动与原因

- 新增「五行石」页（ActivityBar 第 3 项，`IconGem`，随页面保活）：
  - 转换配方列表：投入数量/精力/金币/成功率（一级→三级 100%、三级+一级→四级 48.78%），可切换；
  - 参数：目标成功次数（cishu）、精力单价（与计算/设置共用）、两种石价（默认行情库，MoneyInput 手改标「手填」、可恢复行情价、缺价标红）；
  - 结果卡：净利润（亏损红）、利润率（bp→%）、期望投入次数、期望总成本/收入、缺价名单、口径说明；
  - 「去行情页刷新价格」跳转，缺价时引导。
- `utils/refresh.ts` 一键刷新范围纳入 `wuxingshi[].cong/dao`（优先、去重、仍 ≤200），精炼石价可自动拉取。
- 测试：新增 `WuxingshiPage.test.tsx`（金标准 1→3、切 3→4 的 1/p、缺价/手填/恢复），App smoke 扩到五页；
  前端 **9 文件 / 43 tests** 全绿。

## 关键决策

- 精炼口径与 `jxcg_core::convert` 一致：**不含保管费**（保管费是挂单卖出时的费用；精炼是转换产出，是否挂单由用户决定）。
- 成功率/规则仍为社区口径，页面标注「待实机校准」；实机校准后只需改 `data/wuxingshi.toml`。

## 回归验证

- `bun run build` ✓；`bun run test` 43 passed；`make check-all` 全绿（本轮验证）。
