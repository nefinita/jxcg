# Tauri 目录缓存（AppState）与 reload_catalog

## 改动与原因

- 新增 `src-tauri/src/state.rs`：`AppState` 持有 `RwLock<Option<Arc<Catalog>>>`，首次访问时从 `data/` 加载并缓存。
- `calculate_recipe` / `rank_recipes` / `calculate_convert` / `load_catalog` 改为读缓存，不再每次命令重复解析 TOML
  （排行/计算会频繁调用，全量数据 ~1000 配方后重复解析会明显卡顿）。
- 新增 `reload_catalog` 命令：清缓存并重新读取 `data/`，供数据重新导出/热更新后使用。
- AGENTS.md 同步命令清单与「目录缓存」说明。

## 关键决策

- 缓存放 Tauri 命令层而不是 `jxcg_core`：core 保持纯函数、无全局状态，便于单测与将来复用。
- 加载失败不缓存失败结果（下次命令会重试）；锁中毒仅返回中文错误，不 panic。

## 回归验证

- `cargo check -p jxcg_app` 通过；前端 `reload_catalog` 联调待 UI 落地。
