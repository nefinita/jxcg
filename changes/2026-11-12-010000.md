# JXCG 项目骨架（P1 起步）

## 改动与原因

- 新建 Rust workspace + Tauri v2 壳 + `jxcg_api`（DTO 契约）/ `jxcg_core`（纯计算）/ `jxcg_market`（JX3BOX 行情客户端）三个 crate。
- `jxcg_core` 先落地 `money`（金银铜解析/格式化）、`fee`（5% 四舍五入 + 保管费 + 保本价）、
  `craft`（配方成本/期望产出/利润）、`rank`（排行）、`convert`（五行石转换）、`store`（TOML 装载）。
- 随包数据先给样例（云芝竹沥羹配方 + 五行石转换 + 值集），P2 由 `server_tools/jx3box-export` 全量替换。
- 前端/数据导出的完整实现分别由 app-ui / market-data 两条线并行补齐。

## 关键决策

- 前端包管理器用 **bun**（用户指定）：`bun install` + `bun.lock`；Tauri `beforeDevCommand/beforeBuildCommand` 均为 bun。
- 金额全程 `i64` 铜；费率万分比；概率权重分母 2^20（见 PLAN.md §6）。
- 交易行口径：5% HALF_UP + 保管费 80 银/24h（来源 wind-jx3 / hidewnd 接口交叉验证，待实机校准）。

## 回归验证

- `cargo test --workspace`（money/fee/craft 金标准）与 `cargo check` 待跑。
