# NPC 商店价优先（取价统一口径）

> 作者：core-engine（task-12）。

## 背景与原因
用户指出：料酒（5_31974，商店 6000 铜=0.6 金）、今朝醉（5_32014，商店 1200000 铜=120 金）等
是官方 NPC 无限量售卖的材料，成本应按商店价算，不应被交易行行情价带偏；手填价仍需最高优先。
旧实现优先级是 `jiage`（行情/手填）> 商店价，导致 46 个 NPC 有售物品被交易行价影响。

## 新取价优先级（统一 helper）
`crates/jxcg_core/src/price.rs`（新增，craft/rank/convert/wuxingshi/中间产物展开共用）：
1. `id ∈ shoudong` 且 `jiage` 有值 → **手填价**（`laiyuan = "shoudong"`）；
2. `wupin.shangdianjia > 0` → **NPC 商店价**（`laiyuan = "shandian"`）；
3. `jiage` 有值 → **行情价**（`laiyuan = "hangqing"`）；
4. 都没有 → **缺价**（0 并进 `quejia`，`laiyuan = "quejia"`）。
- 不做「商店/行情取低」：NPC 有售即以商店价为准。
- `price::lookup`（不校验负数，供递归内部）+ `price::qu_danjia`（采用价负数报中文错误）。
- 递归展开内部遇到非法负价按缺价处理（不进负成本；顶层取价仍显式报错）。

## 改动点
- `craft`：删除本地 `qu_danjia`，改用 `price::qu_danjia`；中间产物展开 `zhongjian::purchase_price` 改走 `price::lookup`。
- `convert`（旧 `[[zhuanhuan]]`）：改用统一 helper（请求无手填字段，传空 `shoudong`）。
- `wuxingshi`（面板一键合成）：叶子材料、副产物、目标市场价全部改用统一 helper（同上，空 `shoudong`）。
- `rank`：无独立取价逻辑（走 `craft::Calculator`），自动继承新口径。
- DTO 注释同步：`Wupin.shangdianjia`、`CailiaoMingxi.laiyuan`、`JisuanRequest.jiage/shoudong`、
  `PaihangRequest.jiage/shoudong`、`WuxingshiLianRequest.jiage`。

## 真实数据影响（`data/`，当前 590 配方 / 849 物品）
- NPC 有售物品 **46** 个；直接使用 NPC 材料的配方 **469 / 590**；
  经中间产物展开闭包后受影响配方 **558 / 590**（当前 30 个中间产物本身均非 NPC 有售）。
- 五行石（5_24423~5_24430）均无商店价，面板合成数值不变。
