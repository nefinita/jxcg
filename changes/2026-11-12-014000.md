# Tauri 行情命令接入（load_prices / upsert_price / refresh_prices）

## 改动与原因

- `commands/market.rs` 从占位改为真实实现，接 `jxcg_market`（market-data 交付）：
  - `load_prices`：读应用数据目录 `hangqing/{fuwuqi_id}.toml`；
  - `upsert_price`：手动覆盖单价（刷新时保留手动价）；
  - `refresh_prices`：查 data/fuwuqi.toml 得服务器中文名 → `jxcg_market::refresh_prices` 并发拉 JX3BOX →
    成功覆盖、失败回落 last-known-good → 写回缓存；进度经 Tauri 事件 `refresh-progress`（payload = RefreshProgress）推送。
- 失败/未知服务器返回中文错误串（不 panic）。

## 关键决策

- HTTP 仍只在 `jxcg_market`；Tauri 命令只做「配置读取 + 路径解析 + 事件桥接」。
- 刷新不做自动后台轮询：由界面显式触发（对上游礼貌，也符合用户「断网回落缓存」的预期）。

## 回归验证

- `cargo check -p jxcg_app` 通过；真实拉价/事件联调待前端行情页落地后验收。
