# 开源：GPL-3.0 协议 + GitHub 组织 nefinita/jxcg

## 改动与原因

- 用户要求补 GPL 协议并推送到 GitHub 组织 `nefinita`，开源，权限设置与 jpcg 一致。
- 新增 `LICENSE`：GNU General Public License v3.0（与 jpcg 相同全文）。
- 新增 `.github/CODEOWNERS`（`* @QinThirteen`，触发分支保护 require code owner reviews）、`.github/dependabot.yml`（cargo + npm 每周、target dev）。
- CI `.github/workflows/ci.yml`：新增「金标准回归（计算数值）」job（`cargo test -p jxcg_core --test golden`），
  前端 job 名称对齐 jpcg 保护检查「前端构建 (tsc + vite)」。
- 仓库设置对齐 jpcg：public、默认分支 `dev`、GPL-3.0、issues/projects 开、wiki/discussions 关、合并方式全开、
  `dev`/`beta`/`release` 受保护（PR + 1 review + CODEOWNERS + 线性历史 + 3 个 CI 检查；`dev`/`release` enforce admins）。
- README/AGENTS/PLAN 增加开源协议、仓库地址、分支模型；`data/README.md` 明确数据来源与随仓库分发说明。

## 验证

- `make check-all` 全绿；GitHub 仓库创建后核对默认分支/保护规则/协作者权限与 jpcg 一致。
