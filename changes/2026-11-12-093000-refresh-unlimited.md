# 前端：行情刷新去掉 200 截断（task-8）

## 改动与原因

- 用户明确「行情刷新只刷新 200 个是 bug」。原 `collectRefreshWupinIds` 在 200 处截断：
  五行石 3 个 + 257 个材料就把名额占满，1130 个产物几乎全被丢弃 → 刷新后大量成品仍缺价。
- 修复：`utils/refresh.ts` 删除 `REFRESH_LIMIT=200` 与 `slice`，刷新集合 = 五行石 cong/dao + 全部配方材料 + 全部配方产物
  （去重、稳定排序、无上限）；仅目录完全为空时回退 `catalog.wupin`。
- UI：按钮「一键刷新（N）」+ title「联网刷新当前服全部相关物品（N 个，首次约 1–2 分钟；失败保留最近价格）」；
  刷新中状态栏/进度条显示全量进度；状态栏与设置页展示 `catalog.banben.note` 数据范围。
- 当前全量数据 1264 个相关物品；本赛季过滤后数据 849 个（物品表全部被引用）；随目录自动变化。

## 验证

- `bun run build` ✓；vitest 57 tests 全绿（refresh 3 例：无截断/去重/全覆盖/空目录回退；App 断言无「200」文案）。
- `grep REFRESH_LIMIT` 无残留。行情表格仍保留「前 200 行」纯展示 DOM 渲染上限（与刷新无关，可按需去掉）。
