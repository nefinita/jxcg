# 核心：单件成本字段 + 不可获得材料分类 + 新数据冒烟（task-15）

## 改动与原因

- 用户反馈「中间产物价格没有除期望产出」。核查：单位成本/收入链路均已正确除以期望产出（木板 batch 335,000/2.5 = 134,000；
  百花布 667,000/2.5 = 266,800），歧义来自结果卡只显示「总成本（按批次）」。因此新增显式单件成本字段。
- `JisuanResult.danjia_chengben`（单件成本，铜，HALF_UP）= `zong_chengben / 期望产出总件数`；期望产出为 0 时等于总成本。
- `JisuanResult.bukede`（不可获得材料 id，排序稳定，`quejia` 子集）：缺价材料中「无行情/手填价、无 NPC 商店价、且无任何配方产出」；
  用于 UI 区分「可刷新/补价的缺价」与「无来源材料」（如水纹纸）。
- 新数据冒烟：真实数据 279 配方 / 29 中间产物；排行 279 行全量可排行、空价格表不丢行；NPC 有售物品 44。
- 真实数据除法回归：`furniture_58 木板` 单件 134,000（含 cishu=3：1,005,000/7.5）；`tailoring_1285 百花布` 单位成本 266,800、
  成品配方 `zhongjian[0].danjia == 266,800`、单位链路精力 8；HALF_UP 边界 ±1 铜断言。
- 核查结论：计算链路（顶层材料/中间产物/多产出槽收入/批量/嵌套/五行石/旧转换）未发现漏除。
  唯一展示歧义：`cailiao` 行 `shuliang` 是单次需求、`xiaojia` 含 cishu 总小计，前端表头已写「单次需求」，本次不改语义。
