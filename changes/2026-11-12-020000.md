# 前端四页面（app-ui / task-2）

## 改动与原因

- `examples/jxcg_app` 从占位变成可运行的 React 19 + TS + Vite 前端（bun 管理依赖，`bun.lock` 提交，无 package-lock）：
  - 壳：ActivityBar（可展开）、渐变 logo header（反馈/主题切换）、StatusBar、Toast、深浅色、页面保活；
  - 计算页：配方/手动模式、材料表（行情/商店/手填/缺价标记、可逐行改价）、结果卡与成本构成；
  - 行情页：价格表、一键刷新（`refresh-progress` 进度 + 失败降级）、手改价、粘贴导入、快照、recharts 趋势图、JSON 导出导入；
  - 排行页：三指标/技艺筛选/TOP 柱状图/「包含缺价配方」（`baohan_quejia`）/点行跳转；
  - 设置页：服务器/值集费率/精力单价/技艺等级/自动拉价/主题/数据版本/`reload_catalog`/存档导入导出；
  - API 层：`window.__TAURI__` + 浏览器 mock（镜像 fee/craft/rank/convert 公式），types 镜像 jxcg_api DTO。
- 视觉 token 直接复用 jpcg 的薄荷绿 variables.css/reset.css，保持同一风格。
- 浏览器 mock 服务器 id 已对齐全量数据的完整 pinyin（changancheng/weiwoduzun/shanhaixiangfeng 等）。

## 关键决策

- 前端依赖用 **bun**（用户指定），`trustedDependencies: ["esbuild"]` 显式放行安装脚本。
- 刷新范围默认「配方材料+产物去重、按使用次数排序、上限 200」，避免一次刷全量 800+ 物品。
- 快照/JSON 导入导出 v0 走 localStorage + 逐条 `upsert_price`；后端快照/导入命令列为 P4。

## 回归验证

- `bun install --frozen-lockfile`：165 installs / 207 packages 无变更。
- `bun run build`：tsc + vite ✓（dist JS 696KB / gzip 206KB，recharts 使单包 >500KB 提示，P4 可拆包）。
- `bun run test`：8 文件 / 40 tests 全绿（含四页 smoke、PLAN §6.4 口径、刷新进度+自动快照、排行跳转）。
